# ElectricityDaily（电费日报）

MoviePilot V3 插件：按 Cron 自动登录国家电网 95598 / 网上国网，抓取

- 最近一个已出数日的日用电量（含峰/平/谷/尖，若当地账户提供）
- 账户余额、本月已产生电费、历史欠费
- 第一档 / 第二档 / 第三档等阶梯电量的额度、已用与剩余，以及当前档位

整理成一条通知，经 `self.post_message()` 交给 MoviePilot 的既有通知渠道。

## 配置字段

| 字段 | 说明 |
| --- | --- |
| 启用插件 | 关闭后不注册定时服务 |
| 国网登录账号 | 网上国网 App 登录手机号 |
| 国网登录密码 | 输入框为 password 类型；保存时立即转成 MD5 摘要并加密，明文不会写入配置 |
| 备用登录标识 | 选填，一般为登记在国网的邮箱；主标识被限流时尝试一次 |
| 只推送指定户号 | 选填，留空推送账号下全部居民户号 |
| 定时表达式 | 5 段 Cron，如 `0 8 * * *`，默认每天 08:00 |
| 失败时推送错误说明 | 默认开启；关闭后仅写日志 |
| 保存后立即运行一次 | 通过宿主调度器延迟 3 秒执行一次，不自建后台线程 |

## 凭据安全

1. 配置页 `type: password` 只防肩窥，真正的保护在落盘前：明文密码只存在于内存中，
   立即转换为 95598 登录所需的 32 位 MD5 摘要。
2. 摘要用宿主 `API_TOKEN` 派生的密钥经 `app.sdk.utilities.encrypt` 加密后写入配置；
   配置中的 `password` 字段会被清空。
3. 会话令牌通过 `save_data()` 存在插件数据区；换账号后旧会话自动作废。
4. 日志、通知和详情页只输出错误分类与长度，不输出密码、摘要或令牌。

> MD5 摘要本身等同于登录凭据，请像保护密码一样保护 MoviePilot 配置与备份。

## 错误处理

| 场景 | 行为 |
| --- | --- |
| 密码错误 / 账号异常 | 分类 `invalid_auth`，写警告日志并推送简要提示 |
| 当天被硬拒（RK001） | 分类 `rate_limited`，冷却到当天 24 点，避免反复撞登录 |
| 要求人工验证 | 分类 `captcha_required`，本轮跳过，不伪造成功 |
| 网络/HTTP/非 JSON 回包 | 分类 `cannot_connect`，业务请求失败一次后暂停 30 分钟并退避 |
| 会话过期 | 自动重登一次再重试；仍失败则报告接口异常 |
| 某个接口没有数据 | 其余字段照常推送，缺失项显示“暂无数据”并列入缺失字段 |

[bilezhou/state_grid](https://github.com/bilezhou/state_grid)（MIT）与
[tiejiang29/state_grid](https://github.com/tiejiang29/state_grid)，国密实现随插件附带。
该接口不是国网官方开放接口，可能变更或触发风控；请在自己的账号上评估后使用，
不要高频调用。阶梯字段的别名做了多地版本容错，若你的户号返回结构不同，
可在 `models.py` 的 alias 表中补充键名。
